# Film Shelf 用户端

只读影视片单。首页上方为「推荐」，下方为「近日观影」，可筛选全部、电影或电视剧；各区块每页展示两行海报，可独立翻页。点击作品在当前标签页打开 `/movies/:id`，查看简介、上映或首播日期、可用的剧集集数、主演和观影日期，以及 TMDB / 豆瓣原始条目链接。有磁力链接时展示完整链接和复制按钮。详情主海报优先加载，列表海报和演员照片随浏览按需加载，缺图时显示占位图。

有 TMDB 演员 ID 的主演可点击进入 `/actors/:id`，切换参演电影或电视剧，按日期倒序分页，并标记「推荐」「已观影」「未收录」。已收录作品进入原有详情页；未收录电影进入 `/catalog/movies/:tmdbId`，电视剧进入 `/catalog/tv/:tmdbId`，均为只读详情，浏览不会自动导入数据库。海报和演员照片通过服务端保存到本地。豆瓣演员首版只展示姓名，没有人物关联时不生成演员跳转。演员作品页的片库状态每次请求时读取当前数据库，不随 TMDB 资料缓存而过期。

在项目根目录执行 `bun run dev` 后访问 `http://127.0.0.1:5174`。构建后由 API 的 `/app/` 路径提供访问，各详情页和演员页均支持直接打开和刷新。列表页页码保存在 URL 中，从详情返回时保留原来的区块或演员作品页及页码。页面使用 React Router，共用 API 和 `@film-shelf/shared` 类型；电影海报使用已保存在 `data/posters` 中的本地文件。

用户端没有数据编辑、状态切换、播放、下载或账号功能。观影状态在管理端处理。记录按来源条目管理，豆瓣分季条目可以独立收录，不按片名自动合并不同来源或季别；集数是条目资料，不表示逐集观看进度。

已观影片单按标记已观影的先后倒序展示，磁力链接等其他修改不会改变该顺序；旧片库升级时保留原有相对顺序。详情页直接沿用首页的内容容器宽度。
