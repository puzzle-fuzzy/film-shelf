# Film Shelf 用户端

只读观影片单。首页上方为「推荐」，下方为「近日观影」，各区块每页展示两行海报，可独立翻页。点击电影在当前标签页打开 `/movies/:id`，查看简介、上映日期、主演照片和角色，以及已观影片目的观影日期。有磁力链接时展示完整链接和复制按钮。详情主海报优先加载，列表海报和演员照片随浏览按需加载，缺图时显示占位图。

有 TMDB 演员 ID 的主演可点击进入 `/actors/:id`，浏览 TMDB 收录的全部参演电影，按上映日期倒序分页，并标记「推荐」「已观影」「未收录」。已收录作品进入原有详情页；未收录作品进入 `/catalog/movies/:tmdbId` 只读详情页，浏览不会自动导入数据库。电影海报和演员照片仍通过服务端保存到本地。演员作品页的片库状态每次请求时读取当前数据库，不随 TMDB 资料缓存而过期。

在项目根目录执行 `bun run dev` 后访问 `http://127.0.0.1:5174`。构建后由 API 的 `/app/` 路径提供访问，各详情页和演员页均支持直接打开和刷新。列表页页码保存在 URL 中，从详情返回时保留原来的区块或演员作品页及页码。页面使用 React Router，共用 API 和 `@film-shelf/shared` 类型；电影海报使用已保存在 `data/posters` 中的本地文件。

用户端没有数据编辑、状态切换、播放、下载或账号功能。观影状态在管理端处理。

已观影片单按标记已观影的先后倒序展示，磁力链接等其他修改不会改变该顺序；旧片库升级时保留原有相对顺序。详情页直接沿用首页的内容容器宽度。
